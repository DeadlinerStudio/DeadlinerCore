# 专注时间统计

## 背景

Task 专注计时已有完成会话、今日时长与 Task 累计时长。用户确认下一步是专注时间统计，并嵌入 Android Deadliner 现有统计页的「总览 / 趋势 / 上月」。先前的任务完成数、习惯数量综合统计草稿范围有误，本轮替换该未发布草稿。

## 目标

- 总览将今日专注时间与次数融入今日任务卡，累计/本周/本月时间融入历史卡；本月投入分布放在原统计之后。
- 趋势沿用任务活跃热力图与日/月/周卡片，每张趋势卡同时展示任务成果与专注投入，不新增 Tab、下拉或重复时段卡片。
- 日、月范围分别为近 7 天、近 12 个自然月；周图与已有任务图一致，使用截至今天的 4 个连续 7 日窗口。自然周摘要仍从周一开始。
- 上月将总时长与专注天数融入现有指标网格，次数/平均单次时长为次级信息；每日专注图与已有任务活动图共用卡片。
- 保留已有任务统计内容、三个页签和独立/内嵌/宽屏入口。
- KMP 负责日期范围、聚合、补零、排序和比较；Android 负责本地化与绘图。
- 已完成会话结束、更正、删除、同步，以及 Task 改名/分类变更后刷新；页面恢复时重新计算今天的边界。

## 非目标

- 不新增第四个页签或独立专注分析入口，不新增 Habit 打卡数量或任务成果统计。
- 不改计时状态机、持久化 schema、同步或备份协议。
- 不把任务创建至完成的自然跨度称为专注时长，不推断未计时的投入。
- 不将专注数据发送给已有 AI 月报或改变海报内容；这些需要独立用户确认。

## 用户场景

1. 用户结束一段专注后，在总览看到今日与累计时长更新。
2. 用户切换趋势，看到未专注日期为 0 的时长图，单位为时间。
3. 用户在上月页查看完整自然月的专注记录及相对前月的变化。

## 验收标准

- 只累计未删除 FocusSession 的有效 durationSeconds；活动会话不计入。
- 会话完整归属 startedAt 对应的本地日期；跨午夜不拆分，与现有计时口径一致。
- 本周从周一开始；上月与前月使用完整自然月；缺失日期/期间补零。
- Task 被完成、归档、放弃或删除后，已保存且未删除会话仍计入；现存 Task 显示当前标题，否则使用最近会话标题快照。
- Category 使用 Task 当前分类，无法恢复的分类归入未分类；不声称有历史分类快照。
- 查询支持指定日期范围、Task 或 Category；无范围表示累计摘要与分布，不生成无限日序列。
- 前月为 0 时不显示无穷增长率；展示首次产生记录或绝对变化。
- 统计读取在后台执行，响应数据库变更，加载/空/错误状态可区分。
- Core 单测验证日期边界、删除/改名、分类、对比、补零及筛选；Android 编译与三页签展示验收分开报告。
- 任务与专注核心指标默认同时可见，不能依赖指标切换发现；上下图同一日期范围，纵轴分别为项/分钟，不暗示时长与任务完成率的因果关系。
- Android 使用已有 compose-charts 0.1.7 及图表主题封装，不自绘柱状/折线/分布图；全零专注区显示短空态而非大块空图。
- 用户再次要求极简化：卡片采用统一的短标题/左对齐；专注摘要为一行而非额外 KPI 网格；双图只保留必要图例和一行时长，不重复总数/单位/说明。月报环比为短数值，次数与均值合为紧凑次级信息，单一未分类分布不重复列出。
- 原 AI 和分享仍维持任务统计口径，分享入口明确此范围；不把新增专注数据悄悄发给 AI。

## 风险与约束

- 仅替换本会话新增且无客户端使用的统计草稿；已发布 Focus/Overview 接口保持兼容。
- 不提交或覆盖工作区其他改动；Android OverviewActivity 已有 UI 改动，需要原位保留。
- 复用当前 Overview 的卡片、主题、滚动与柔光玻璃 chrome，新增内容文件控制在 1000 有效行以内。
- iOS/HarmonyOS 后续消费同一 Core 合同；本轮平台落地按此前重点验收 Android。

## 当前实现状态

Core 聚合、仓库和订阅已实现。初版独立卡片及后续文字偏多的融合布局被用户否定，Android 已按最新要求完成极简修订：原三个页签内嵌短摘要、紧凑双图及月报指标，保留项目图表库与导航结构。最终构建和深色/浅色大字体设备测试通过，证据位于 tasks.md 的当前版本验收记录及 screenshots/minimal-*；旧截图仅供归档。视觉设计是否满足用户预期仍由用户确认，iOS/HarmonyOS UI 尚未接入。

## 习惯专注概览增量（2026-10-12）

现有合计和排行已包含 Habit，但未提供稳定的类型时长拆分，低于前三名的习惯投入不直观。本轮在现有三页签内补齐，不新增导航或大型卡片：

- KMP 摘要和每日/周/月点提供任务、习惯的秒数拆分，合计等于两者之和；类型筛选可查询全部 Habit，而不混用 taskUid。
- KMP 同时提供近 7 天、近 12 月、连续 4 周的摘要，Android 不另写期间聚合规则。
- 总览今日/累计摘要增加一行紧凑「任务时长 · 习惯时长」；有习惯投入时才展示。上月复用时长指标的次级文本；趋势复用原专注图及短摘要，点击点可看对应类型拆分。
- 不增加第三张类型图，不改项目 compose-charts、不改任务成果/热力图、AI/分享口径。
- 验证 Habit-only、混合、同 UID、启动日/跨日、删除会话、删除/改名/换分类的习惯、补零及订阅；三个页签展示习惯时长且任务完成数不变。
- 保留旧构造与字段；新增拆分/期间摘要为可缺省的读模型字段，旧投影不编造类型时长。本轮不升级 schema 或同步格式。

当前增量代码与 API 文档已完成：Core 定向测试 30 项、Android 单元测试 310 项通过，Android APK 与 iOS/OHOS Kotlin 目标编译通过。最终设备结果见 tasks.md 阶段 7 验收记录。
