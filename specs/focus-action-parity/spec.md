# 专注操作闭环与三端一致性

## 背景
用户选定审计待办 F01/F02/F04/F05/F06/F07。沿用真实绑定计时、原子目标变更与平台原生材质，不同步 Android 新总览看板。

## 目标
- 当前 Task 的完成/放弃/归档/删除、Habit 的归档/删除需明确确认，保存有效时间并执行原操作；取消不写入。
- 确认冻结 sessionUid；旧确认不得结束同一目标的新会话。零秒可清空但不能制造零秒记录；异常时保留计时与目标并提示。
- 鸿蒙 Habit 右滑归档/专注、左滑编辑/删除，多选禁用；Task 完成/专注/放弃，完整右滑仍完成。
- 已保存 Task 会话结果可补完成任务；不重新保存会话，不影响另一目标计时；若该 Task 已开启新会话则拒绝旧结果操作。
- iOS 专注联动习惯变更后列表必须重读数据库，保留当前日历日期与搜索条件，不能只重算旧缓存。
- 三端区分通知失败、时钟异常、12h长计时和过长恢复警告，提供清楚可见的中文/Android双语提示。

## 非目标
F03/F08/F09、概览/看板、全量历史入口、同步格式、数据库迁移、导航/状态管理重构；不新增顶栏专注入口。

## 用户场景
右滑正在专注的任务完成，确认后结束并完成；删除正在专注的习惯仅保存时间；倒计时到点后补完成 Task；取消确认或旧会话确认保持业务状态安全。

## 验收标准
定向 SQLite 测试覆盖原子保存/目标变更、零秒、过期确认、重复补完成、删除会话和新活动保护；三端构建、原生源码/宿主合同，能用设备验证则记录范围，无设备不声明渲染通过。

## 风险与约束
多仓库脏工作区逐块保留；新命令及展示字段为可缺省增量，无 schema/sync breaking。确认不能在只读数据库层自动执行。大型批次结束后统一编译，鸿蒙显式 DEVECO_HOME，新改动文件不超过1000有效行。
